# AgentCrew 桌面界面设计

## 页面结构

工作台以当前任务为阅读中心。左侧使用 256 像素侧栏，集中展示品牌、任务入口、记忆与技能、运行中心、自动化和最近任务。最近任务与页面导航共用侧栏，任务名称取服务端保存的标题；标题为空时使用真实首条指令的文字片段，完整指令保留在对话中。任务状态、最近时间与两行标题共同支持任务识别，搜索只过滤当前身份可见的任务。

正文保持不超过 820 像素的阅读宽度。用户指令使用右侧紧凑气泡，员工回复使用连续正文，保留作者、时间和复制入口。执行详情默认收起，展开后使用 320 像素右侧区域展示当前运行的步骤、工具参数、结果和后台记录。审批、回答问题与效果核验始终在正文中提供操作入口，关闭右侧区域不会隐藏需要用户决定的事项。

## 颜色与字体

| 用途 | 颜色 |
| --- | --- |
| 正文表面 | `#FFFFFF` |
| 侧栏表面 | `#F7F8FA` |
| 主要文字 | `#252936` |
| 辅助文字 | `#626A78` |
| 区域边界 | `#E7EAF0` |
| 操作强调 | `#356FEA` |

界面采用 macOS 系统字体，正文使用 14 像素与 1.9 倍行高，任务标题使用 20 像素，辅助信息使用 11 至 12 像素。界面名称、任务状态和按钮均使用中文；工具名称、文件路径、模型标识与代码保持真实原文。主操作使用蓝色，普通导航与历史记录使用浅灰选中状态，审批使用暖色提示。状态同时具有文字说明，颜色只提供辅助识别。

## 对话与执行记录

Markdown 由 react-markdown 与 remark-gfm 解析，支持标题、强调、列表、表格和代码块。代码块提供复制操作，宽表格在自身区域横向滚动。原始 HTML 不执行，URL 使用解析库的协议校验；文档链接和图片链接提供复制入口。回复直接显示已保存的模型正文，模型工具调用前的说明保留在对话中，辅助模型的整理回合按真实来源区分。

工具调用概览按当前运行提供可展开的记录。具体工具、执行状态、调用时间、目标和结果均来自已保存事件。模型回合完成与工具执行完成分别展示。后台摘要及长执行编号放入可展开记录，当前审批则展示工具、目标、风险、调用内容和持续授权范围。一次决定与永久规则分别保留原来的权限限制和确认步骤。

产物使用服务端探测后的文件状态。可用文件显示名称、路径、大小与定位入口，生成中、失败和缺失文件分别显示状态并停用定位操作。文件位置由现有窄 preload API 调用系统文件管理器，正文中的文件路径可选择、复制和换行。

## 输入与窗口行为

输入区固定在正文底部，可随内容增长至八行。附件以文件名展示，完整路径通过提示保留；工作空间、员工与文件访问范围集中在输入区底部。Enter 发送、Shift+Enter 换行，输入法组合期间不触发发送。发送、排队、停止、审批阻断和待核验状态继续使用服务端提供的操作许可。

用户停留在最新内容时，新增事件保持对话跟随；用户向上阅读历史时保留位置，并提供返回最新内容的按钮。窗口低于 980 像素时侧栏转为图标导航，任务列表可以展开；窗口低于 1100 像素时执行详情使用独立覆盖区域，Escape 关闭区域并恢复触发按钮的焦点。设置入口固定在左下方，设置页面集中提供桌面行为、员工、组织、权限和审计功能。

## 验证方式

类型与构建使用 `npm run typecheck`、`npm run build`。Markdown 解析与内容边界使用 `node tests/markdown.check.mjs`，文字和焦点对比度使用 `node tests/contrast.check.mjs`。工作台交互使用 `node tests/workbench.integration.mjs`，通过真实 Electron、后端与模型检查消息格式、复制、搜索、刷新、审批、文件产物和窗口布局。桌面生命周期使用 `node tests/m3-lifecycle.mjs` 检查通知、设置、退出与调度状态，错误恢复使用 `node tests/m3-desktop-errors.mjs`。检查产生的独立数据与结果保存到已忽略的 `desktop/.artifacts/`。
