# AgentCrew 设计系统

设计文件：[AgentCrew · macOS 数字员工平台](https://www.figma.com/design/l1bD8BxkwKAMSchNRPdQxX)。画布中的「00 页面结构与流程」包含页面结构和线框图；「01 高保真与原型」包含桌面窗口及状态；「02 组件与规范」包含颜色变量、色板和可编辑组件。产品行为依据 [PRODUCT.md](../product/PRODUCT.md)、[USER-FLOWS.md](../product/USER-FLOWS.md) 和 F001–F010；画布中的示例任务、文件和时间仅用于展示布局。

## 窗口与布局

画板以 1440 × 900 的 macOS 窗口为基准，顶部标题栏高 52。完整工作台从左到右依次为 180 的导航侧栏、240 的任务列表、弹性任务正文和 280 的运行详情。正文保留至少 32 的左右内边距；底部输入区保持在可见区域，长对话独立滚动。任务列表和整条导航侧栏使用不同的收起控制，右侧运行详情另有独立控制。右侧收起时，任务状态与审批卡仍显示在正文。导航收起后，顶部继续提供新建任务和待处理事项入口。

窗口宽度低于 1100 时隐藏任务列表和运行详情，分别通过顶部按钮打开；低于 980 时导航缩为 66 宽的紧凑模式，仍保留可识别的页面名称或辅助提示。正文与输入区不得因侧栏覆盖而失去操作空间。桌面设计最窄画板为 960 × 900；更窄的窗口应保持可滚动的正文与固定输入区，不设计手机页面。页面导航只渲染当前已由实际服务提供的页面，未实现页面不显示入口。设计文件展示完整目标页面，用于后续交付。

## 颜色与排版

| 用途 | 值 | 使用位置 |
|---|---|---|
| 主表面 | `#FFFFFF` | 正文、卡片、输入区 |
| 侧栏 | `#F6F8FB` | 导航与辅助区域 |
| 弱背景 | `#EEF3FA` | 选中行、次级提示 |
| 主文字 | `#17243B` | 标题与正文 |
| 次文字 | `#5B6A7D` | 时间、路径说明与辅助信息 |
| 边界 | `#DCE3EB` | 卡片、输入区和分隔线 |
| 主操作 | `#315EB5` | 主要按钮、链接、焦点 |
| 成功 | `#16845B` | 已完成、文件可用 |
| 警告 | `#A35C13` | 等待审批、待核验、暂停排队 |
| 危险 | `#BF4148` | 失败、拒绝、取消 |

中文使用 Noto Sans SC，macOS 实现优先采用系统中文字体；英文、数字和路径使用系统界面字体。页面标题 28，任务标题 22，区块标题 18，正文 14，辅助文字 12–13，按钮 13–14。正文行高至少为字号的 1.5 倍；状态不能只用颜色表示，必须同时显示文字。白底上的正文及辅助文字保持清楚的对比度，禁用操作仍说明原因。

间距使用 4、8、12、16、24、32 的序列。按钮高度 36–40，输入区和主要卡片圆角 12，紧凑标签圆角 8。危险操作使用红色且显示具体影响范围；等待人工处理使用暖色背景，在侧栏、任务顶部和正文保持相同的状态文字。

## 组件与交互

按钮提供主要、次要、危险、禁用和键盘聚焦状态。输入区支持多行内容，持续显示当前工作空间、员工、材料和文件访问范围；执行中显示“发送后将排队”，等待审批和待核验时显示阻止原因。审批卡固定展示工具、目标、关键参数、风险、调用内容和持久授权范围，四种决定均为独立按钮。选择“始终允许”或“始终拒绝”时，决定前必须再次看到工具与资源范围。

任务行显示标题、最近时间和状态；任务标题与指令过长时允许两行并省略其余内容，悬停或聚焦时可查看全文。文件路径使用可选择和复制的文本，可换行或横向滚动，不截去末端文件名；产物卡同时展示名称、类型、大小、路径与可用状态。时间线同一事件在正文与运行详情中使用相同状态，展开后展示实际工具名称、参数、结果、时间及事件编号。模型生成的说明以文字来源标记，真实工具结果以事件与文件状态标记。

所有可点击目标均支持键盘 Tab 到达，焦点使用 2 像素主操作色外描边，并提供可读名称。Enter 或 Space 激活按钮，Escape 关闭弹层并返回先前焦点；审批、停止、退出、取消排队等决定不得因关闭弹层自动提交。新状态到来时只更新相关区域与辅助技术播报，避免打断正在输入的文字。遵循 macOS“减少动态效果”设置，原型使用即时切换；实现中的转场在该设置开启时关闭。

## 设计文件的交付状态

Figma 中的 Frame、文字、颜色变量及按钮组件均可编辑。Figma Starter 计划的 MCP 调用额度在建立原型连线时耗尽，目前仅“无任务 → 新建任务”点击连线完成；其他画面可在设计文件中逐张查看，不能视为已通过可点击原型验证。完整交互判定与缺失契约见 [ui-spec.md](./ui-spec.md)。
