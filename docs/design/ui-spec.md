# AgentCrew UI 交互规格

设计文件：[AgentCrew · macOS 数字员工平台](https://www.figma.com/design/l1bD8BxkwKAMSchNRPdQxX)。本文件依据 [PRODUCT.md](../product/PRODUCT.md)、[USER-FLOWS.md](../product/USER-FLOWS.md) 和 F001–F010 规定页面操作。接口与事件文件目前为草案；表中的目标行为不表示接口已经实现。前端导航只显示已经有真实服务支持的页面，状态只从实际快照、事件、文件探测和桌面壳结果取得。

## 页面结构与定位

| 页面 | 设计文件中的画面 | 主要对象 |
|---|---|---|
| 工作台 | `工作台｜无任务`至`工作台｜窄窗口`，以及审批失效、队列取消、产物状态和定时任务审批 | 任务、指令、审批、排队、产物、当前运行 |
| 运行中心 | `运行中心｜回放`、`运行中心｜失败与缺失`、`运行中心｜事件定位` | 执行记录、尝试、事件、审计报告 |
| 数字员工管理 | `数字员工管理｜列表`、`数字员工管理｜编辑` | 员工配置、技能、连接器、记忆、授权 |
| 自动化 | `自动化｜列表`、`自动化｜创建`、`自动化｜运行记录` | 定时配置、预授权、每次触发 |
| 管理中心 | `管理中心｜授权`、`管理中心｜只读诊断` | 演示身份、角色、资源授权、审计链 |
| 设置 | `设置｜桌面行为`、`设置｜退出确认` | 关窗行为、休眠、数据目录、退出 |

默认进入工作台。窗口完整时显示导航、任务列表、正文及右侧运行详情。任务列表、整条导航和右侧详情分别收起；收起后的按钮保留可访问名称与焦点状态。宽度小于 1100 时，列表与详情由按钮打开；小于 980 时采用紧凑导航。顶部状态和正文审批入口不得随详情面板一起消失。

## 工作台状态与操作

| 状态 | 入口与触发条件 | 页面反馈与允许操作 | 状态变化与失败处理 |
|---|---|---|---|
| 无任务 | 启动后没有任务或点击新建任务 | 显示工作空间、小文、材料入口与空白输入；发送前显示文件访问范围 | 输入首条指令后才创建任务；离开空白编辑状态不保存空任务 |
| 新建任务 | 点击顶部或侧栏的“新建任务” | 可选择员工、文件或文件夹；文件显示导入位置，文件夹显示原路径和读写范围 | 材料无权访问、路径失效或超限时在发送前显示逐项原因；部分材料失败需显示实际接受结果 |
| 启动中 | 发送首条有效指令 | 新任务进入列表，显示已保存指令与启动状态 | 创建失败保留输入内容并显示服务端错误；不出现已创建任务的假状态 |
| 执行中 | 收到 `run.started` 与步骤事件 | 正文显示当前动作、已完成步骤和工具结果；右侧选择步骤显示参数、结果与时间；可停止、继续输入 | 连接暂断显示重新连接；工具失败定位到实际步骤，保留已完成内容 |
| 排队 | 执行中发送后续指令 | 发送前提示“发送后将排队”；发送后显示原文、顺序和队列数量 | 正常结束后按队首启动；提交失败时保留输入草稿并显示错误 |
| 等待审批 | 未获规则放行且允许人工决定 | 任务行、顶部和正文同步提示；卡片显示工具、目标、参数、风险与持久范围；输入发送禁用 | 审批提交后记录决定、操作者与时间；请求失效或参数变化时刷新卡片，不再批准旧请求 |
| 停止后暂停 | 点击“停止执行”且存在排队指令 | 当前执行显示取消过程，原有步骤和产物保留；队列显示“已暂停排队” | 取消完成后不得自动启动；继续处理从队首启动，取消排队需明确选择指令范围并保留发送历史 |
| 完成 | 真实运行完成 | 显示最终回复与真实可用产物；可打开文件、查看回放、继续发送 | 文件打开失败显示原因；文件移动或删除后转为缺失状态并保留原路径 |
| 失败 | 真实运行失败 | 显示错误摘要、失败步骤和可展开详情；保留已有产物 | 不清空历史；自动接续下一条的条件由执行契约明确后显示 |
| 中断 | 应用或 sidecar 异常退出后恢复 | 显示中断位置、历史尝试、已保存步骤和产物；无待核验调用时显示“恢复执行” | 恢复创建新尝试；请求失败保留中断状态及错误 |
| 待核验 | 外部调用已发出而结果无法确认 | 显示目标、参数、发起时间、已知证据；可确认已执行或未执行 | **恢复执行禁用**，不得自动重试或越过调用；提交失败仍留在待核验状态，无法查证时保持原状 |
| 重新连接 | 界面连接或 sidecar 暂断 | 保留最后已知状态，提示正在重新连接及日志入口 | 重连后先取快照，再按事件游标补齐；连接故障不直接判定任务失败 |

左侧任务列表收起后仍有“新建任务”和“展开任务列表”；整条侧栏收起后这两个入口与待审批提示位于顶部。右侧收起后正文保留当前步骤摘要和审批卡。长任务文本在正文完整显示并可滚动，列表最多显示两行；路径允许复制及换行，末端文件名不得被永久遮蔽。

## 关键操作的完整反馈

| 操作入口 | 触发条件 | 即时反馈 | 成功后的状态 | 失败处理 |
|---|---|---|---|---|
| 工作台“添加文件” | 新建任务或允许补充材料的状态 | 显示文件名、原路径、数量与大小限制、导入目标 | 单个文件复制到任务资料目录，原文件不变；重名使用可辨认名称 | 无权限、路径不存在、超限或复制失败时逐文件说明，不把材料标为已接受 |
| 工作台“选择文件夹” | 新建任务 | 显示原位置路径及访问范围 | 文件夹保留在原位置；后续工具仍接受权限判断 | 不可读或范围非法时阻止发送并说明原因 |
| 工作台“发送” | 有非空指令且无审批或待核验阻断 | 按状态显示“启动中”或队列序号 | 首条创建任务；后续直跑或排队 | `409`、校验失败及连接错误保留草稿，刷新真实状态 |
| 步骤“展开”与右侧时间线 | 已有保存事件 | 展示事件编号、工具、目标、参数、结果、时间和来源 | 选择同一事件时正文与右侧一致；可进入运行中心 | 事件缺失显示缺失，不以模型文字补齐 |
| 顶部“停止执行” | 当前运行允许取消 | 按钮显示取消中，防止重复触发 | 当前执行取消；未开始的队列转为暂停 | 取消请求失败保留原运行状态并显示错误 |
| 暂停队列“继续处理” | 队列非空、没有审批或待核验阻断 | 显示即将启动的队首指令 | `queue.resumed` 后队首开始执行 | `409` 时刷新队列与阻断原因 |
| 暂停队列“取消排队指令” | 至少一条待处理指令 | 弹层列出选中指令或“全部”及影响数量 | 指定项移出队列，原始发送记录和取消事件继续可见 | 失败时保留选择并刷新队列 |
| 待核验卡“确认已执行 / 确认未执行” | 用户已查证外部结果 | 显示调用内容、证据说明输入与本次判断 | 写入核验事件和审计，解除该调用的阻断；随后由用户恢复 | 请求已失效时刷新；提交失败不改变核验状态 |
| 中断卡“恢复执行” | 没有待核验调用 | 说明将新增一次执行尝试 | 新尝试显示独立边界，历史审批、产物和步骤继续可查 | `PENDING_VERIFICATION` 时显示调用清单并禁用恢复 |
| 产物卡“打开” | 状态为可用且文件仍存在 | 调用 macOS 默认应用 | 保留当前任务，记录文件可用状态 | 文件缺失或系统无法打开时显示原因和原路径；生成中与失败产物不提供打开操作 |

## 四种审批决定与范围

审批卡显示调用的 `call_id`、工具、规范化目标、关键参数、风险和不可变内容标识；“始终”范围同时显示工具和资源匹配范围。用户点击决定后，按钮进入提交中，提交成功显示操作者、时间及最终结果。等待期间不接收新指令。命中已有允许规则的调用直接执行；明确拒绝、缺少能力或越过安全边界时显示拒绝原因，不出现审批卡。预置小文在已授权工作空间内的部分写入操作直接执行。

| 决定 | 授权范围 | 调用结果与记录 |
|---|---|---|
| 仅本次允许 | 当前 `call_id` 与不可变参数 | 当前调用继续，记录一次性允许 |
| 始终允许 | 卡片明确展示的工具与资源范围 | 当前调用继续，并保存可在员工管理页查看及撤销的允许规则；范围外调用仍需判断 |
| 仅本次拒绝 | 当前 `call_id` 与不可变参数 | 当前调用失败，员工依据实际失败结果决定后续步骤 |
| 始终拒绝 | 卡片明确展示的工具与资源范围 | 当前调用失败，并保存可查看及撤销的拒绝规则 |

收到 `APPROVAL_STALE` 时卡片转为“审批已失效”，停用四个旧按钮并重新获取待处理请求。数字员工提出定时任务时，同一审批卡另显示时间、时区、指令、目标任务和预授权工具及资源；未经用户决定不生效。无人值守的定时运行只允许员工授权与任务预授权的交集，范围外调用直接拒绝并留下记录和通知。

## 其他页面

运行中心从任务步骤或自动化运行记录进入指定执行记录。左侧按任务选择执行记录和初次、恢复尝试；中间按事件序号播放、暂停、单步前进，并可展开模型请求摘要、工具参数与结果、审批、产物和错误；右侧审计报告的事件引用跳到原始记录。报告未生成、事件缺失、产物缺失分别显示真实状态。报告来自辅助模型时明确标明来源。页面刷新后从保存事件恢复顺序与选中位置。

数字员工管理页的“创建”“编辑”“撤销授权”均展示岗位、技能、连接器、记忆及已授权范围。保存后新任务使用新配置；历史任务继续展示创建时快照，实时撤销的授权影响下一次权限判断。失败时保留表单并逐字段说明错误。禁用能力后不再显示为可用；员工不能给自己增加权限。

自动化创建表单显示名称、指令、员工、时间、时区、放入现有任务或新任务、目标任务以及预授权工具和资源。保存前展示下一次运行及授权摘要；成功后列表显示启用状态、创建来源和最近结果。停用操作显示影响的任务。每次运行记录可返回任务和运行中心，分别显示已触发、已错过、已跳过、失败、范围外被拒和待核验；已错过不补跑，前次仍在执行时已跳过不积压。关机或应用真正退出期间不执行，关闭窗口且留在菜单栏时继续等待触发。

管理中心明确展示“演示身份”提示，角色、资源授权和连接器变化显示来源、操作者与时间；校验审计链后显示结果与问题位置。校验失败进入只读诊断，保留原始审计记录查询、断点定位、导出和重新校验，禁用派活及工具执行。设置页提供“关窗即退出”、阻止系统休眠和数据目录位置。真正退出前若存在运行中、等待审批或 24 小时内待触发的定时任务，确认弹层逐项说明影响；取消退出返回原任务。sidecar 重启超过限制时显示错误和日志路径，通知点击后进入对应任务。

## 后端 Agent 需要补充的契约

| 契约缺口 | 受影响的页面状态与操作 |
|---|---|
| `/api/conversations` 创建请求没有 `workspace_id`，没有发送前的材料与范围预检；`/api/limits` 只有文字描述而无可生成类型的响应 schema | 新建任务无法可靠展示工作空间、导入限制、无权路径和发送前访问范围 |
| 任务列表、消息、执行记录、步骤、定时任务列表及运行记录的响应多为文字描述，缺少完整 schema、分页与稳定状态字段 | 任务状态徽标、排队位置、尝试边界、运行记录异常状态和刷新恢复无法生成明确类型 |
| `Approval` 缺关键参数、当前匹配规则、四种决定的持久范围及决定者和时间字段；`permission.requested/resolved` 载荷未定义具体结构 | 审批卡无法完整展示不可变调用，历史决定和授权范围无法核对 |
| 缺少员工、技能、连接器、记忆、授权规则、演示身份、角色、资源授权的查询与修改接口 | 数字员工管理和管理中心无法显示真实对象、保存编辑或撤销授权 |
| 缺少审计报告查询、事件引用、审计链校验和只读诊断接口；`audit.reported` 没有结构化引用 | 运行中心无法从报告跳到原始事件，管理中心无法定位校验失败 |
| 定时配置 `schedule` 是自由对象，预授权缺校验与预览响应；运行记录无明确 schema，事件缺范围外拒绝、待核验和通知的关联字段 | 自动化创建时无法核对时区与下次运行，记录页无法可靠呈现错过、跳过、被拒与待核验 |
| `PendingVerification` 缺调用目标的结构化字段、所属尝试与核验历史；核验提交响应缺操作者、时间与事件编号 | 待核验卡和恢复后的尝试边界无法完整追溯 |
| 产物缺少打开前的文件探测接口或明确刷新时机；桌面壳原生操作的成功与错误返回没有契约 | 文件被移动或删除后的“缺失”反馈、打开失败和日志位置无法稳定显示 |
| 侧边导航的可用能力清单、sidecar 连接状态、桌面设置读写及退出影响清单没有契约 | 导航可能展示未实现页面，重新连接、只读诊断和退出确认无法只依赖真实状态 |
| 失败终态后排队指令何时自动接续缺明确状态与事件条件 | 失败页面无法准确提示下一条指令是否即将启动 |

以上缺口交由后端 Agent 修订 `contracts/openapi.yaml` 与 `contracts/events.md`，产品行为继续以产品文档和功能规格为准。现有草案虽列出队列继续、取消与核验提交路径，这些路径仍需实现和实测。

## 用户流程检查记录

| USER-FLOWS.md 流程 | 对应画面 | 检查结果 |
|---|---|---|
| 首次打开、无任务、关窗与只读诊断 | 工作台无任务、设置桌面行为、设置退出确认、管理中心只读诊断 | 画面已绘制；桌面真实效果与原型点击未验证 |
| 新建任务、材料、文件范围 | 工作台无任务、新建任务 | “无任务 → 新建任务”点击连线已验证；选取文件与发送后的连线未完成 |
| 执行、排队、审批与停止 | 工作台启动中、执行中、排队、等待审批、停止后暂停、审批已失效 | 画面已绘制；四种决定和队列操作连线未完成 |
| 结果、失败、产物 | 工作台完成、失败、产物可用、产物缺失 | 画面已绘制；本机打开文件需真实实现验证 |
| 中断、待核验与恢复 | 工作台中断、待核验、重新连接 | 画面已绘制；禁止恢复的界面状态已标注，连线未完成 |
| 定时配置与每次运行 | 自动化列表、创建、运行记录、工作台定时任务审批 | 画面已绘制；预授权和异常记录需要后端契约支持 |
| 回放、员工、治理 | 运行中心、数字员工管理、管理中心 | 画面已绘制；原型连线与真实数据验证未完成 |

Figma Starter 计划的 MCP 工具调用额度在批量建立跳转时用尽，工具返回调用上限错误。当前可编辑画面共 33 张高保真 Frame 和 10 张线框图；可点击原型仅完成一条连线，不能声明已逐条走通。额度恢复后应依此表连接并逐条演练全部流程，再由后端 Agent 修订并冻结接口契约。
