# ADR-005 · 权限三级闸门与审计哈希链

状态：已接受（Q4/Q14/G1/G2 + v1.1/v1.2 修订）

**决策**：工具执行走三级闸门——① 元数据分级（bash 只读 = 白名单首词**且无元字符**，白名单不含 find/python；路径 realpath 规范化；http 受 allowed_hosts 约束）→ ② 员工规则表（deny>allow，pattern 匹配，挂员工名下可回收）→ ③ 人工审批四选项（绑定 input_hash）。无人值守（cron）= 员工规则 ∩ 任务预授权，任一未命中即拒。一切敏感动作入哈希链；链头每 100 条快照到库外文件；校验失败进只读诊断模式（不干活但可诊断/恢复）。
**理由**：放行的是"动作+对象"而非动作（G1）；fail-closed 保审计可信，诊断模式解决"验证按钮不可用"矛盾。
**影响**：种子组织演示"默认拒绝"；agent 永远拿不到治理工具（提权防线）。
