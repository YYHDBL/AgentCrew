# ADR-006 · 禁止 mock 与假测试

状态：已接受（用户确认，v1.3；覆盖早期"双层测试"提案）

**决策**：不设假 Provider / 假模型 / 全局 fake clock；模型集成测试使用**当前配置的真实上游模型**（成本控制走 aux 槽）+ 真实文件产物 + 真实进程中断（kill -9）；断言落在数据库状态与产物文件，不断言模型措辞。自有纯函数（reducer/权限判定/调度计算）的参数化单测**不属于 mock**，正常保留。
**理由**：用户明确要求；真实执行路径才验证真实契约。
**影响**：回归测试有 API 成本与时长成本——用例精选、断言稳定（查库不查文案）；调度测试用秒级 every 计划真实验证。
