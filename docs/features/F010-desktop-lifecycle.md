# F010 · 桌面运行与设置

**用户目的**：知道应用关闭窗口、退出或服务中断后，正在执行的任务会怎样。

正常情况下，关闭窗口使应用留在 macOS 菜单栏，任务与定时任务继续运行；菜单栏提供重新打开窗口和真正退出。设置页提供“关窗即退出”开关、数据目录位置和阻止系统休眠的设置。用户真正退出前，若有运行中或等待审批的任务，或近期将触发的定时任务，确认界面说明会受到影响的项目。任务完成、失败和等待审批通过桌面通知提醒；用户点击通知返回对应任务。

sidecar 中断时，工作台显示重新连接状态；恢复后补齐事件。超过自动重启限制时，界面显示错误与日志位置。系统休眠、电脑关机和应用真正退出期间的定时行为以 [F007](./F007-automation.md) 为准。审计链校验失败时启动只读诊断界面。

**验收**：真实任务运行时关闭窗口，菜单栏仍能找回任务；真正退出时显示准确的影响说明；sidecar 重启后界面恢复同一任务状态；设置变更后关窗行为与说明一致。
