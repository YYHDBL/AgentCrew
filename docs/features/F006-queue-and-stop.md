# F006 · 排队指令与停止执行

**用户目的**：数字员工忙碌时继续交代工作，并在停止当前执行后掌握剩余指令是否继续。

同一任务内一次只执行一条指令。运行期间输入区说明“发送后将排队”；发送后正文保留指令，排队区显示数量与先后顺序。当前执行正常完成后自动启动队首指令。等待审批期间输入区说明原因并暂时禁止发送。其他任务可以独立运行。

用户点击“停止执行”后，当前执行进入取消过程；尚未开始的排队指令保留原顺序并暂停。取消完成也不能自动启动下一条。界面显示“已暂停排队”，提供“继续处理”和“取消排队指令”操作；取消时清楚标明作用的指令范围，原始发送记录与取消记录保留。只有用户明确选择继续处理，队首指令才启动。失败终态的自动接续规则沿用运行时契约，并在界面显示将要执行的下一条指令。

**验收**：运行中发送两条指令，顺序和执行次序一致；停止当前执行后，排队指令不会自行启动；继续处理后从队首执行；取消排队指令后无遗漏启动。暂停、继续和取消的接口及事件需补入后端契约。
