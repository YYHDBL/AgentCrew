# F005 · 权限请求与审批

**用户目的**：在数字员工执行需要人工决定的操作前，查看具体动作及范围，并保留可追溯的决定。

权限规则先判断调用。已授权的资源范围内直接执行；明确拒绝、缺少能力或禁止执行时直接显示拒绝原因；其余需要人工决定的调用暂停并显示审批卡。预置“小文”在工作空间内的部分写入操作已有授权，写入文件不必然触发审批。审批卡显示工具、目标资源、关键参数、风险说明及不可变的调用内容。任务列表和顶部同时提示等待，用户能够从任何滚动位置返回审批卡。

审批提供“仅本次允许”“始终允许”“仅本次拒绝”“始终拒绝”四种决定。“始终”决定显示将保存的工具与资源范围，用户可在数字员工管理页查看和撤销。决定提交后保留操作者、时间和结果；拒绝后该次调用失败，后续由数字员工根据失败结果处理。若请求已处理或参数发生变化，旧卡不能再次批准。等待审批期间不接收新指令。

**验收**：一次确需人工决定的真实调用展示准确目标和参数；四种决定分别产生预期结果；保存允许规则后仅相同授权范围内放行；范围外操作仍需决定；刷新界面后审批状态和记录不丢失。
