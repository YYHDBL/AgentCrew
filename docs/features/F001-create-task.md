# F001 · 新建任务与派活（含排队）

- **目标**：用户创建任务线程、下发指令；忙时排队自动接续（UF1/UF6）
- **主流程**：新建任务（选员工）→ 输入指令 → 发送 →（空闲：立即执行 ｜ 运行中：入队并可见 → 前一任务终态后自动出队执行）
- **边界**：审批挂起时禁发（提示先处理）；排队顺序 FIFO；取消当前任务后队列自动顶上
- **契约**：`POST /conversations`、`POST /conversations/:id/instructions`（202/409）、`GET .../state`（FSM + 队列）；事件 `run.queued/started`
- **验收**：真实任务下，第二条指令排队可见且自动接续；审批挂起时发送得到 409
