# F001 · 新建任务与提供材料

**用户目的**：用自然语言交代任意办公任务，同时知道员工将在哪个工作空间、哪些本地材料上工作。

用户点击“新建任务”后看到空白输入状态。当前仅有一名可用员工时自动选中“小文 · 办公助理”，有多名时允许切换。用户可以选择本地文件或文件夹，并在发送前看到工作空间、材料与访问范围；未选择时使用工作空间的数据目录。选取的单个文件复制到任务资料目录，原文件保持不变；选取的文件夹在原位置使用，路径和访问范围必须明确展示。点击发送才创建任务、保存首条指令并启动执行。空白输入离开时不留下空任务。任务标题由首条指令生成，列表显示标题和状态。

选取材料只说明材料来源，不能绕过员工能力或权限规则。路径不存在、无权读取或不属于所显示的访问范围时，发送前给出具体原因。导入文件遇到重名时保留原文件并使用可辨认的新名称。允许的文件大小和数量由接口契约明确，并在选取时显示限制；选取外部文件夹后，工具的读取与修改仍受员工能力、规则和审批判断。

**验收**：从空白界面发送一项用户自选的任务，真实创建任务并开始执行；工作空间与访问范围在发送前后保持一致；关闭空白编辑状态后任务列表无空记录；无权访问的材料不能被表现为已接受。
