# F008 · 运行回放与审计

**用户目的**：根据保存的事件还原一次执行，找出每个决定、工具结果和错误的来源。

运行中心按任务查找执行记录。打开记录后展示事件时间线，可按顺序回放并定位模型请求摘要、工具调用参数与结果、权限决定、产物和错误。恢复执行所创建的新尝试与旧尝试在同一任务下分别可见，前后关联清楚。审计报告显示结论、失败原因及对应事件位置；点击报告中的事件可以跳到原始记录。任务步骤和自动化运行记录均能进入相应执行记录。

事件记录是回放依据。审计报告由辅助模型生成时标明其性质，并保留可核对的原始事件。事件缺失、产物文件缺失或审计报告尚未产生时，页面分别显示实际状态，不填充推测内容。审计链校验入口及校验结果在管理中心可见；校验失败时进入只读诊断状态。

**验收**：完成一项真实任务后，用户能从任务进入运行中心并逐步查看同一次执行的工具和审批记录；失败报告能跳到对应事件；刷新后回放顺序一致。
