# F009 · 数字员工与授权管理

**用户目的**：知道每名数字员工能做什么，并能更改或撤销其能力与权限。

数字员工管理页展示员工岗位、状态、技能、连接器、记忆及已授权清单。用户可以创建或编辑员工，并查看每项技能、连接器和权限规则的来源与当前状态。撤销授权后，后续工具选择和权限判断立即按最新规则执行；已创建任务仍保留创建时的员工配置快照，用于解释当时的执行环境。删除或禁用能力后，界面不能继续表现为员工仍可使用该能力。

管理中心展示演示组织、工作空间、演示身份、角色、资源授权和审计记录。身份切换明确标为演示操作；角色和授权检查使用实际规则执行。用户可校验审计链，校验失败时只能进入只读诊断操作。数字员工不能给自己增加角色、连接器或权限规则。

**验收**：撤销一项员工能力后，该员工下一次任务无法调用该能力；授权范围变化能影响下一次权限判断；演示身份受到角色规则限制；历史任务仍可查看当时的员工配置与审计记录。
