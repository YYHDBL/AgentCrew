# F002 · 查看执行过程

**用户目的**：随时知道数字员工已经做了什么、正在做什么，以及结果来自哪次真实调用。

发送指令后显示启动、执行、完成或失败状态。中间按时间展示指令、回复和步骤概览；展开步骤查看工具名称、目标、参数、结果和时间。右侧可收起的运行详情显示同一事件记录的时间线。当前步骤有进行中标记，已经完成或失败的步骤保留各自结果。模型生成的解释与真实工具结果分别标识。任务失败后仍可查看此前步骤和产物。

界面通过已保存事件和状态快照恢复。连接中断时显示重新连接状态，重连后从游标补齐记录；刷新页面也要能还原状态。连接暂断与任务执行失败分别呈现。右侧面板收起时，顶部和中间仍显示当前状态及需要用户处理的事项。

**验收**：真实 GLM 任务执行时，工具调用与最终结果均可查看；断开并恢复界面连接后，步骤顺序与状态和后端记录一致；任务失败时可定位失败步骤，而历史内容不消失。
