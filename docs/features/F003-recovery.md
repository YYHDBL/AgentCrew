# F003 · 中断恢复与结果核验

**用户目的**：异常退出后继续工作，同时能辨认外部操作是否已经发生，避免无依据的重复执行。

应用重开后显示中断任务及已保存的历史。系统对可以核验的文件操作检查实际结果并补齐记录。无法确认结果的外部调用显示“待核验”，包含目标、参数、发起时间和已知证据；该调用不得自动重试，任务不得越过它继续执行。用户查证后可以记录“确认已执行”或“确认未执行”；如果无法查证，保持待核验。核验决定保留操作者、时间和证据说明。

没有待核验调用时，用户点击“恢复执行”。系统新建执行尝试，把历史事件、产物和副作用记录提供给数字员工；此前的步骤、审批和产物继续可见。数字员工随后发出的新调用按新决定处理。界面显示本次尝试与历史尝试的边界。

**验收**：在真实执行中强制结束应用，重新打开后能查看中断位置；已确认完成的文件操作不被无依据地重复执行；结果不明的外部调用阻止自动继续；用户提交核验结果后，事件记录与界面状态一致。核验提交接口仍需补入后端契约。
