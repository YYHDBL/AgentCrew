# F007 · 定时任务

**用户目的**：把重复工作交给数字员工，并清楚控制无人值守期间可使用的能力与文件范围。

用户在自动化页面创建任务，填写名称、指令、数字员工、时间与时区、使用现有任务或新建任务，以及预授权的工具和资源范围。页面显示下一次运行时间、启用状态、创建来源和最近结果。用户可以停用任务并打开每次运行记录。数字员工通过对话提出创建定时任务时，审批卡同时展示时间、指令和预授权范围，用户批准后才建立任务。预授权和员工授权均匹配时调用才执行；范围外操作直接拒绝并留下记录及通知。

macOS 电脑关机或应用真正退出时不会执行。应用重新运行后，错过的时间点记为“已错过”，不补跑；上一次执行尚未结束时记为“已跳过”，不积压。执行失败按后端既定重试规则处理；存在待核验调用时停止自动重试。关闭窗口且应用仍留在菜单栏时，定时任务继续等待触发。

**验收**：用户创建并触发一项真实定时任务，能找到其执行记录；范围外调用被拒绝并通知；错过和运行冲突各留下可见记录；数字员工提出创建任务时，未经用户批准不会生效。
