# AgentCrew 工作台页面与用户流程（讨论稿）

> 产品负责人：Codex；供用户确认后移交 UX Agent 绘制线框图。本文定义页面职责与操作结果，不规定组件尺寸和视觉细节。
> 已确认的产品决定：停止当前执行时保留并暂停未开始的排队指令；由用户选择继续或取消。

## 产品范围与视觉方向

macOS 单用户桌面应用，界面使用中文。工作台承载新建任务、持续交流、观察执行、处理审批、排队、停止、恢复和查看产物。另有设置页面。完整运行中心、员工管理、组织管理和定时任务按产品范围文档另行设计，不在工作台放不可用的导航入口。

界面中的“任务”是一条可持续交流的工作记录。用户在同一任务内追加指令，每条指令触发一次执行；运行中追加的指令按发送顺序排队。这样任务列表展示的是工作记录，过程区展示的是其中每次执行。

视觉采用浅色、克制的 macOS 风格：明亮背景、清晰文字、少量强调色、轻量分隔。任务内容占据主要空间。左右区域均可收起，用户可以在窄窗口中集中阅读任务内容。

## 工作台的三个区域

**左侧任务栏**：顶部提供新建任务；下方按最近活动排列任务，每项显示标题与当前状态。任务列表可以单独折叠，整条侧栏也可以从窗口工具栏收起。侧栏收起时，工具栏仍保留新建任务与重新展开入口。设置入口位于侧栏底部，并可通过应用菜单访问。

**中间任务区**：顶部显示任务标题、执行员工、状态和当前执行的停止操作。正文按时间顺序显示用户指令、员工回复、过程记录、审批请求与产物。过程记录概览展示当前动作和结果；展开后查看每次工具调用。待审批卡始终留在正文中；用户滚动离开时，顶部状态入口能返回该卡。底部固定输入区，运行中发送的指令进入队列；等待审批期间说明无法发送的原因。

**右侧运行详情**：默认收起，保留能够点开的状态入口；展开后展示当前执行的步骤时间线。选中步骤后查看工具名称、参数、结果和发生时间。右侧不重复呈现完整聊天内容，也不承担跨任务回放与审计报告。收起右侧后，顶部仍显示运行或待审批状态。

## 用户流程

1. **新建任务**：点击“新建任务”进入空白编辑状态，预置员工“小文 · 办公助理”。用户直接输入指令并发送，此时创建任务并开始执行。标题取自首条指令，可在后续任务管理功能中修改。只有一名员工时不弹出员工选择窗口。
2. **观察执行**：发送后出现“启动中”和“正在执行”。正文实时追加过程记录；当前步骤展开，历史步骤可收起。工具调用的参数和结果可从过程记录或右侧详情打开。连接中断时显示“正在重新连接”，重连后从事件记录补齐内容，不把连接问题显示成任务失败。
3. **处理审批**：申请卡明确显示操作、目标资源、关键参数和“总是允许／总是拒绝”将保存的规则范围。四个决定都有可发现入口：仅本次允许、总是允许、本次拒绝、总是拒绝。决定提交后卡片保留决定与时间；处理前输入区停止发送新指令。侧栏和顶部同时显示待审批状态，避免请求被滚动位置遮住。
4. **追加指令**：执行中允许输入和发送，发送前提示“将排队”。发送后，用户消息进入正文，输入区上方显示排队数量；展开可查看待执行指令和顺序。当前执行结束后自动开始下一条。待审批期间暂不接收新指令，避免用户误以为已经进入队列。
5. **停止执行**：顶部“停止执行”取消当前执行，并暂停该任务中尚未开始的排队指令。界面保留排队内容，明确显示“已暂停排队”；用户可决定继续处理或取消排队指令。停止记录保留在正文中。这样用户中止错误操作时，不会意外启动依赖它的下一条指令。
6. **恢复中断**：应用重开后，运行时中断的任务显示“已中断”和“恢复执行”。用户主动恢复；恢复时保留既有过程与产物记录。存在执行结果无法确认的外部操作时，界面显示“待核验”及操作详情，暂停继续执行，直到用户核验结果。
7. **完成与失败**：完成时展示最终回复和产物卡；产物卡显示文件名、类型、大小、状态与“打开”。失败时展示错误摘要和详情入口，保留已经完成的过程与产物。用户可以在同一任务中继续发送指令。

## 需要覆盖的页面状态

空白任务、空闲、启动中、执行中、等待审批、指令排队、已停止、已中断、待核验、执行失败、执行完成、连接中断与重新连接。左右区域的展开与收起是独立状态；任何布局下都要能找到待审批请求、当前状态和新建任务入口。

## 移交 UX Agent 之前需要补充的产品与接口契约

- 后端已有“待核验并由用户确认后继续”的恢复要求，但当前任务接口列表没有确认核验结果的操作。需要定义“确认已执行／确认未执行／暂时无法确认”的用户结果、后端处理和接口，UX Agent 才能画出完整恢复流程。
- 当前调度规则会在执行取消后自动启动下一条排队指令，与“停止执行后暂停排队”的产品行为冲突。需要调整队列状态与继续、取消排队指令的接口。
- 当前任务接口只列出创建、读取、发送、停止、恢复和审批。任务重命名与删除缺少接口，也涉及历史记录与审计保留；因此工作台讨论稿不提供这两个操作。
- 设置页面展示“关窗即退出”和数据目录；关闭窗口、真正退出与任务运行期间的提示遵循桌面壳文档，UX Agent 需要画出对应提示状态。

## UX Agent 交付范围

绘制工作台展开态、左右收起态、空白任务、执行中、待审批、排队、完成、失败、中断恢复、待核验和重新连接状态，以及设置页面。逐项标注用户点击后的状态变化；视觉稿与交互稿必须以本产品定义和最终确认结果为准。
