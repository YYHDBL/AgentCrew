# AgentCrew 用户流程

> 本文从用户的操作与可见结果描述完整工作过程。页面视觉细节由 UX Agent 设计，接口细节由后端维护。各流程中的状态和操作必须能从真实数据得到。

## 首次打开与进入工作台

应用启动后检查本地服务和数据状态。正常时打开工作台；无任务时显示可直接输入的空白任务状态，并提供任务文件夹或材料入口。已有任务按最近活动展示，运行中、等待审批、中断、失败与完成各有可辨认状态。用户可以收起任务列表、整条左侧栏和右侧运行详情，收起后仍能新建任务、查看当前状态并找到待处理审批。

应用关闭窗口后留在菜单栏继续运行任务和定时任务；用户通过菜单明确退出。退出前如有正在运行、等待审批或即将触发的定时任务，界面说明后果。设置中的“关窗即退出”改变这一行为。审计链校验失败时进入只读诊断界面，显示问题位置及恢复入口，禁止继续派活与执行工具。

## 新建任务与提供材料

用户点击“新建任务”，中间区域出现空白输入区，顶部显示当前工作空间和数字员工。只有一名可用员工时自动选中；有多名时可以更换。用户可以输入任意办公要求，并选取本地文件、文件夹或使用工作空间的数据目录。单个文件导入任务资料目录，原文件保持不变；选取文件夹时在原位置使用。材料与文件夹访问范围在发送前可见；无法访问的路径在此时给出原因。用户点击发送后，系统创建任务、保存首条指令并开始执行，任务出现在左侧列表。空白编辑状态离开前没有创建空任务。

用户无需在新建时填写任务标题。系统从首条指令生成便于辨认的标题；后续如提供重命名能力，应保留原始指令及审计记录。导入文件遇到重名时保留原文件并使用可辨认的新名称；文件大小与数量限制由接口契约给出，界面在选取时显示。

## 查看执行与继续指挥

发送后，任务先显示“启动中”，再显示正在执行的动作。中间按时间展示用户指令、员工回复、步骤概览和工具状态；展开步骤可查看工具名称、目标、参数、结果与时间。右侧运行详情展示同一执行记录的时间线，选择步骤时显示详细信息。模型生成的中间内容须与已经执行的工具结果区分。连接中断时显示重新连接状态，恢复后按事件游标补齐缺失记录；连接故障不自动判为任务失败。

当前指令尚在执行时，用户仍能发送下一条指令。发送前输入区提示“发送后将排队”；发送后该指令及其顺序可见。当前执行正常完成后自动处理队首指令。系统在同一任务内一次只运行一条指令；用户切换到其他任务不影响当前任务。审批等待期间输入区说明需要先处理审批，发送操作暂不可用。

## 处理权限请求

当调用不在已授权范围内且允许人工决定时，当前执行暂停，任务列表、顶部状态和对话内审批卡同时提示等待。审批卡说明数字员工要做什么、目标资源、关键参数、风险、当前批准所覆盖的内容以及“始终”决定将保存的工具与资源范围。用户可选择仅本次允许、始终允许、仅本次拒绝或始终拒绝。决定提交后保留决定、操作者和时间，执行继续；拒绝意味着该次调用失败，数字员工根据实际结果决定后续步骤。已失效或参数变更的审批请求不能继续批准，界面需刷新请求。

命中已有允许规则的调用直接执行；命中拒绝规则、缺少能力或被安全边界禁止的调用直接显示拒绝结果。定时任务无人值守时只在员工授权与任务预授权的交集内执行，范围外直接拒绝并通知，不保留无人处理的审批窗口。

## 停止执行与处理排队指令

用户在任务顶部点击“停止执行”后，当前执行进入取消过程，已经发生的步骤与产物继续保留。尚未开始的排队指令保持原顺序并显示“已暂停排队”，不会因取消完成而自动启动。用户可以点击“继续处理”让队首指令运行，也可以取消排队指令；取消决定需要明确指令范围，历史发送记录继续保留。正常完成或失败结束后的自动接续遵循执行契约；只有用户主动停止会使剩余队列暂停。

## 查看结果与继续工作

执行完成后，中间展示最终回复和实际产物。每个产物显示名称、类型、路径、大小及文件状态；点击“打开”调用 macOS 默认应用。文件被移动或删除后，卡片显示缺失与原路径，不假装能够打开。用户可以在同一任务继续发送“把这份内容改成表格”等指令；新执行记录与先前产物保持关联。执行失败时显示错误摘要和可展开详情，已完成的文件和步骤仍可检查。

## 中断、待核验与恢复

应用或 sidecar 异常退出后，重新打开应用会看到中断任务和已经保存的步骤。系统核验可以确认结果的调用并补齐状态；无法确认结果的外部调用标为“待核验”，展示发起时间、目标、参数和已知证据，禁止自动重试及恢复后继续调用。用户查证外部结果后提交“确认已执行”或“确认未执行”；无法查证时保留待核验状态。核验结果写入事件与审计记录。没有待核验调用时，用户点击“恢复执行”，系统创建新的执行尝试，保留此前回复、步骤、审批和产物，并继续处理任务。恢复后的新工具调用按照新调用处理，不能仅凭参数相同判定为已经执行。

## 创建与管理定时任务

用户可从自动化页面创建定时任务，或在对话里要求数字员工创建。创建时需确认执行时间与时区、执行指令、数字员工、放入现有任务还是新任务，以及允许使用的工具与资源范围。数字员工提出创建请求时，审批卡同时显示定时配置和预授权范围，用户决定后才生效。自动化页面可查看下一次运行、启用状态、创建来源和运行记录，并能停用任务。

到点且应用可运行时，每次触发都留下独立记录。错过的时刻标为“已错过”，不补跑；前次仍在执行时标为“已跳过”，不堆积。权限超出预授权范围、执行失败与待核验状态在运行记录和通知中可见，用户可打开对应任务查看过程。

## 查看回放、审计与员工配置

用户在运行中心选择一条执行记录，按时间查看用户指令、模型请求摘要、工具调用、审批决定、结果和错误，并按事件顺序回放。失败审计报告能定位到对应事件；报告文字不能替代原始记录。用户可以从任务中的步骤进入运行中心，也可以从自动化运行记录返回对应任务。

用户在数字员工管理页创建或编辑员工，查看其岗位、技能、连接器、记忆和已授权清单；改动影响后续任务的配置选择，已经建立的任务保留原始配置快照，实时撤销的授权仍需生效。管理中心支持查看演示身份下的角色与资源权限、调整授权和校验审计链。单用户本地使用与演示身份切换应在界面中明确区分。
