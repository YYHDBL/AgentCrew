# 屏幕地图

> 维护：产品线 ｜ **屏幕的具体形态（布局/视觉）归设计 Agent**；本文件只定"有哪些屏、各自承载什么、何时出现"。

## MVP（第一片）

| 屏 | 承载 | 对应功能 |
|---|---|---|
| Cowork 工作台（唯一主屏） | 任务列表 + 聊天流 + 过程展示 + 审批 + 产物 + 排队指示 | UF1–UF6 全部 |
| 设置（极简） | 关窗即退出开关、数据目录 | — |
| 空态 | 无任务引导 | UF1 前置 |

## 增量片 → 未来屏

| 片 | 屏 |
|---|---|
| P1 员工管理 | Agent Studio（员工档案/soul/已授权清单/记忆管理入口） |
| P2 记忆 | 记忆管理页（并入 Studio 或独立，设计定） |
| P3 运行中心 | Run Center（跨任务列表/Replay/审计报告；MVP 主屏若含步骤面板则为其扩展） |
| P4 组织治理 | Admin Center（成员/角色/grant/连接器/审计链验证） |
| P5 定时 | 定时任务管理（位置设计定） |
| P6/P7 | 无新屏（分发/多 Agent） |
