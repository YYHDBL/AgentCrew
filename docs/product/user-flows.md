# 用户流程（MVP 六条）

> 维护：产品线 ｜ 供设计与后端对齐用；具体界面形态由设计 Agent 决定。

- **UF1 派活**：打开应用 → 新建任务（选"小文"）→ 输入指令（如"整理 inbox 文件夹"）→ 发送
- **UF2 看过程**：任务进行中 → 实时看到步骤/工具调用（读文件、执行命令）逐条出现 → 状态实时变化
- **UF3 审批**：小文要写文件 → 审批卡出现（操作+参数+风险）→ 用户四选一 → 任务继续/该调用被拒
- **UF4 收产物**：任务完成 → 产物文件卡（名/大小/打开）→ 点开用系统应用核对
- **UF5 崩溃恢复**：任务中途强杀应用 → 重开 → 任务显示"已中断" → 点恢复 → 继续执行 → 完成（文件无重复副作用）
- **UF6 排队**：小文干活时再发一条指令 → 提示"将排队" → 当前任务完成后自动接续执行
