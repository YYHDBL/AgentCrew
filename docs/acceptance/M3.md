## 验收资产

`scripts/seed/m3_automation_data.py --output-dir <独立材料目录>` 生成真实订单 CSV、任务背景、备注和独立预期值，记录输入 SHA-256，并保留模型生成的输出。生成器拒绝运行数据库所在目录及内容冲突，重复调用保持输入稳定。

在 `desktop/` 执行 `node tests/m3-acceptance.mjs`，脚本创建独立数据目录，使用当前配置的真实模型，从工作台计算真实订单并生成文件，执行三种定时计划与权限拒绝，读取失败审查报告并定位原事件，再经真人页面确认发布技能、核查版本与账本、独立授予能力并在下一任务读取技能。随后检查员工计划提案的批准前后唯一性与真实触发，以及成员权限和审计链。

每次运行在被忽略的 `desktop/.artifacts/m3-acceptance-*` 保存脱敏 HTTP 请求/响应、完整 SQL 与结果、任务与 occurrence 标识、作业、事件水位、文件 SHA-256/mtime，以及四个页面的 DOM 与控件布局。脚本失败会保存实际错误并以非零状态退出。模型未生成有效提案时，技能发布流程保持未通过。
