# M2-06 · HTTP/MCP 连接器与执行边界验收

日期：2026-10-04，Asia/Shanghai。本卡12项专项测试通过，连接器、Grant、技能版本、记忆API、后台审批及工具回归共76项通过。真实main/aux使用deepseek-v4.1-flash。执行 `AGENTCREW_TEST_CONFIG_SOURCE=<已忽略的有效配置> UV_CACHE_DIR=../data/m2-intermediate/uv-cache uv run --no-sync pytest -x -q tests/test_governance_connectors.py tests/test_governance_grants.py tests/test_governance_skills.py tests/test_memory_api.py tests/test_memory_review.py tests/test_tools_builtin.py --tb=short --basetemp=../data/m2-intermediate/pytest-connectors-release`，见[当前代码测试输出](assets/M2/06/tests.txt)和[专项输出](assets/M2/06/connectors-tests.txt)。依赖同步及OpenAPI检查分别见[同步结果](assets/M2/06/dependencies.txt)、[契约结果](assets/M2/06/openapi.txt)。

HTTP连接器使用真实HTTPX传输，主机、端口、DNS地址及每个重定向目标均检查硬边界。DNS解析后固定连接地址，TLS保留原主机SNI且连接池按原来源隔离；代理、环境配置和自动重试关闭。服务端认证仅绑定配置来源，跨来源重定向不转发认证；模型认证头、Cookie、Host及幂等头直接拒绝。响应正文、派生产物及Content-Type采用实际已登记凭据脱敏。

[HTTP执行证据](assets/M2/06/http-connector.json)保存任务、调用、Grant、SQL、事件及审计序号。真实服务向SQLite事务写入操作，以唯一identity_key实现去重；同一task_run_id和call_id两次调用实际操作数量1，正文和认证SHA一致。外部幂等仅用于配置中具有明确去重承诺的精确方法及路径，这类端点禁止重定向；普通写操作维持outcome_unknown。主机拒绝、认证替换、撤销后调用均阻止执行。跨来源重定向接收方实际没有收到来源凭据。

MCP使用[官方Python SDK](https://github.com/modelcontextprotocol/python-sdk)，锁定已验证的1.26.0，支持stdio及Streamable HTTP。连接初始化、分页发现、输入和输出schema、实际call_tool与关闭全部通过SDK。目录名称携带稳定连接器身份，长名称保持64字符内；执行时重新比较已批准目录及当前连接器修订。远程schema引用、重复名称及重复分页游标明确拒绝，避免协议校验产生额外网络请求。缺少管理员风险声明的工具需要审批且采用outcome_unknown。

[stdio证据](assets/M2/06/stdio-connector.json)保存真实发现目录、任务及调用、文件SHA和mtime、环境名称、退出进程身份以及SQL。MCP服务实际fsync保存一条材料；环境只传递PATH、HOME、LANG、TZ、TERM，记录系统运行时派生环境名称。进程宿主关闭时清理整个进程组。实际保护文件读取、写入和网络访问均失败，保护文件保持原正文。[网络MCP证据](assets/M2/06/network-mcp.json)保存真实Streamable HTTP写入和文件校验。连接器更新后的旧目录执行拒绝，撤销后未产生第二次保存。

连接器创建、读取、校验、禁用、重复请求、陈旧修订、member拒绝和错误响应通过实际HTTP核查，见[10项请求响应](assets/M2/06/http-identity.json)。公开配置只有credential_configured，错误响应不回显输入凭据；治理写入沿用同事务事件、审计及幂等记录。[SQL证据](assets/M2/06/identity-sql-audit.json)记录事件水位22、审计序号22。

Grant回归使用真实模型请求及SIGKILL。小刚声明没有HTTP，等待审批撤销后派发数量0，已派发bash取消后保存既有文件并终止子进程；重启恢复保持原任务、技能版本、记忆快照和两次尝试。恢复后的新审批按run.resumed事件水位识别并通过真实API拒绝，可能出现的实际提问通过真实回答API处理，未要求模型采用指定措辞。[恢复证据](assets/M2/06/grants/recovery-revocation.json)与[完整请求及SQL](assets/M2/06/grants/http-identity.json)记录真实结果。公开材料按有效模型凭据、身份标识及连接器认证扫描，匹配数量0；真实库及中间日志保存在忽略的data目录。
