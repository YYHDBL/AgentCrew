# M3-04 调度、时区、错过与冲突验收

日期：2026-10-05，Asia/Shanghai。实施及本卡自动验收完成。单进程调度使用真实时钟及每计划asyncio等待，登记前复查enabled、revision与持久next_run_at；同一串行写通道保存唯一发生、下一次时间、审计及事件。现有会话未结束任务、等待人工、待核验、暂停队列及排队均构成冲突，登记skipped，不追加执行队列。手动发生使用相同冲突判定。

时间计算使用croniter6.2.4及ZoneInfo。every按持久anchor保持节奏；DST不存在时刻跳过，重复当地时刻只选择第一次绝对时刻。大量错过保存首个scheduled_at、missed_through及missed_count，every使用算术计数，cron使用成熟库展开及按小时/分钟分组统计；一天秒级cron核对86400个错过点，未创建执行任务。修改为过期at时使用当前schedule的anchor判定missed，停用与修改之后旧revision不能登记发生。

真实HTTP分别创建临近at、每秒every及六字段秒级cron，三种计划均到期登记一次fired。每秒计划后续冲突登记skipped，scheduled_at唯一；停用后没有新增发生。真实SIGSTOP/SIGCONT暂停4.2秒跨过every到期窗口，恢复后保存missed覆盖及计数，初始fired数量保持1。另将at设置为3秒后到期，实际暂停进程4秒，恢复迟延约1秒，仍按超过两秒的实际停顿窗口保存missed。独立250毫秒heartbeat与定时器共同核对真实观察区间，正常长等待不会被当成暂停。

真实SIGKILL发生在at到期前，停止期间跨过时间点；重新启动只登记一条missed，task_run_id为空，next_run_at为空且该一次性计划停止。错过记录、计划及发生标识、实际PID、信号时刻、覆盖时间、审计及SQL水位保存于[实际请求](assets/M3/04/http.json)、[进程信号](assets/M3/04/process.json)、[调度SQL](assets/M3/04/scheduler-sql.csv)、[进程SQL](assets/M3/04/process-sql.csv)和[完整查询](assets/M3/04/queries.sql)。本卡验证到期及发生登记；实际Harness文件任务由M3-05接入，自动化七项最终计分由M3-15完成。
