# M1-06 · 任务摘要与近期工作记录

日期：2026-10-02，Asia/Shanghai。实施基础为 M1-05 `0182fa97a859e635301508b7c1582cd44cccb5f9`，交付分支为主仓库 desktop-shell。

## 实现与生命周期

任务完成事件及回复提交后创建独立 summary 作业。SQLite v7 保存唯一触发任务、来源事件水位、会话与身份范围、aux 模型、配置版本及不含凭据原文的配置快照、usage、错误和调用记录。aux 沿用所属会话的稳定供应商标识。后台模型事件进入 memory_job_calls，作业状态事件使用独立 job_id，保持前台任务、回合、模型调用及审批投影计数不变。

session_summaries 对任务和作业分别执行唯一约束，正文限定1至200字符，完成摘要禁止修改和删除。摘要、作业 completed、memory.summary_created、memory.job_status 及审计在一个串行写入事务中提交。已经开始提交的结果使用现有 shield 和等待机制完成事务；随后到达的取消保留已提交结果。空正文、超限、凭据或真实模型执行失败保留失败状态及实际结果，前台已经提交的完成状态保持有效。

新任务读取本会话最近五条已完成摘要，按创建时间和标识取最近记录，再按时间顺序放入历史的近期工作记录区域。三库和冻结 Skill 索引保持原快照。疑似注入摘要保存原文，模型工作记录替换为 BLOCKED，检索过滤原文。摘要使用原生 FTS5 trigram，短中文使用参数化子串查询，沿用身份范围、排序与游标；会话归档后继续可检索。

辅助工作只在前台空闲时开始。接收新建会话、后续指令、排队指令、继续队列或恢复请求时，通过共享取消范围停止新辅助动作，等待模型流关闭和作业终态提交。材料复制和目录验证在工作线程执行。会话锁与辅助取消锁采用一致顺序。关闭后端先完成作业取消与 HTTP 连接池关闭；启动将未完成作业标记 interrupted。完成事件已经提交、作业尚未建立的进程终止窗口也保存唯一 interrupted 作业，缺少摘要的任务继续接受前台指令。
