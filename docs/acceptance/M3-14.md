# M3-14 通知与桌面生命周期

日期：2026-10-10，Asia/Shanghai。功能实现完成；系统通知实际点击与真实 macOS 休眠/唤醒仍待平台验收，卡片尚未判定完整通过。

## 实现与边界

preload 只提供固定的通知展示、桌面信息、偏好更新和退出确认方法，以及固定事件订阅与清理函数。旧 `notify`、`keep-awake` 暴露已清理。通知先由后端 compare-and-set 认领，仅 `claimed=true` 可以请求系统展示；`badge` 只进入应用内通知中心，`warning`、`error` 请求系统提醒。通知分页、未读计数、已读状态与关联任务导航均使用真实接口，身份变化会清除旧缓存并取消旧请求。

桌面设置在专门的设置页面显示关窗退出、防止自动休眠、数据目录和执行边界。设置保存等待主进程完成应用，HTTP 与 IPC 失败显示实际原因；请求代数防止旧偏好覆盖新值。通知消费在可预期的请求失败后继续轮询，读取失败保留具体提示。协议错误仍由错误边界报告。

退出弹窗展示真实退出影响快照，包含活跃任务、待核验与未来计划，支持取消、确认及键盘焦点。真正退出会清理 sidecar 与子进程；重新启动后过期计划登记为 missed。应用退出或电脑关机期间计划不会执行，错过的计划不会补跑。防止自动休眠开关仅在应用运行期间有效。

## 验收方式

`desktop/tests/m3-lifecycle.mjs` 使用独立数据目录、真实 Electron、真实模型、SQLite、文件和进程信号，检查通知认领去重、分页、身份清理、隐藏窗口执行、SIGSTOP/SIGCONT、退出快照及清理、重新启动 missed。`desktop/tests/m3-desktop-errors.mjs` 通过独立 SQLite 的真实写锁制造接口失败，检查具体错误显示和服务恢复后的继续消费。

检查资产与阶段回归结果统一登记在 [M3 阶段报告](M3.md)。公开证据仅保留脱敏 HTTP、SQL、关联标识、事件水位、文件校验与 DOM 布局记录；真实配置、运行库和中间结果位于被忽略的目录。

系统通知实际点击需取得操作系统点击、窗口前置与关联任务导航的完整证据。真实 macOS 休眠/唤醒需取得 `power-events.log` 与 `runtime.power_changed` 的关联记录。进程暂停检查不能替代真实电源事件，这两项继续标为未验证。
