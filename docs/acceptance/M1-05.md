## 实现与回归

system 仅包含冻结的名称和不超过60字符的描述。正文读取保持实时，保存实际修订；支撑文件读取不替代正文读取。创建前必须读取同范围目标的不存在状态，修改前必须读取本回合正文。patch 要求 old_text 恰好匹配一次，edit 替换整篇正文，files 中 null 删除支撑文件。读取修订、当前修订和准备事务修订分别校验，陈旧修订返回 REVISION_CONFLICT。

Skill 复用已有持久化意图、同目录原子替换、串行写入事务、审计链、事件和不可修改账本。正文、描述、支撑文件完整内容、前后 metadata 和 SHA 随修订保存；成功和失败请求均绑定原始输入，重复执行保持幂等结果。恢复历史追加新记录；恢复首次创建前状态清空材料，保留服务身份和递增修订，读取该修订后可以重新编辑。归档完整保留支撑文件和原位置清单。

名称、描述、正文、依据、文件路径与支撑文件正文执行凭据、风险及投毒检查。高风险材料经人工审核后参与模型读取；疑似注入材料保留在磁盘，模型读取明确拒绝，冻结索引过滤相关描述及路径。完整正文读取使用独立统计，相同 call_id 与 entry_id 去重；索引展示及支撑文件读取保持正文命中计数不变。
