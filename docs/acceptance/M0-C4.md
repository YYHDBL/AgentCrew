## 3. 与设计的偏差及决策说明

1. **协议从 OpenAI 兼容改为 Anthropic 兼容**（M0-cards §3 原选型）：用户 key 实测 OpenAI 端点报 1113 无额度、Anthropic 端点全功能可用。已按"重大技术决策补 ADR"纪律写入 **ADR-009**；协议差异封在适配层（设计本意），DeepSeek（M4）仍走 OpenAI 协议成第二适配器。
2. **归一事件比设计枚举多两项**：`thinking_delta`（GLM 默认输出思考块，如实暴露、循环侧可忽略）与 `tool_call_started`（v1.6"拼装完成前对前端只报进行中不带参数"的载体）。ADR-009 已注明。
3. **流中断"可重试一次续跑"的实现边界**：上游无续传原语——未产出任何事件前的中断按分类退避重试（≤3 次）；已产出事件后的中断发 `error(network, retryable=true)` 交上层决策，不自动重发（重发会重复输出）。已如实记入 provider-verification.md"对 C8 的接口约定"。
4. **上游不一致实测**（流式下 thinking disabled 不保证关、缓存字段恒 0、多轮可不回传 thinking 块）均如实记录在 provider-verification.md，消费侧策略已给（忽略 thinking_delta）。
5. main/aux 当前都指向 glm-5.3-flash（用户提供的 key 即 flash 资源）；换主力模型只需改 `data/config.json`，双槽配置化验证过。
