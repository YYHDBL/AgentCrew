# 前端任务入口

实施计划与任务卡统一维护在 [桌面前端实施计划](../plans/2026-09-29-desktop-frontend.md)。后端任务编号继续使用 [M0 C1–C12](./M0-cards.md)，前端使用 FE 编号，完成状态分别记录。

当前已有 Electron / React 桌面骨架、工作台布局和纯界面交互。**C10 已通过真机验收**：sidecar 监管、连接状态、托盘驻留、单实例及退出清理见 [验收记录](../acceptance/M0-C10.md)。C11 的任务功能与 C12 的贯穿验收尚未完成。

本轮停在 C10，等待所有者说“继续”。后续业务接口按后端交付的实际契约接入，不使用假服务替代验收。

C10 对应 **FE03** 的 sidecar 启动、监管和连接信息，以及 **FE09** 的 M0 桌面生命周期范围；两部分已随 C10 验收。FE09 规划中的设置页、真实运行影响清单和定时任务提醒仍依赖后续后端能力，状态保持等待依赖。
